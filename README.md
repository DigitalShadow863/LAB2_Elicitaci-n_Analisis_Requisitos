# Laboratorio de Elicitación y Gestión de Requisitos
## Descripción

Este repositorio contiene el desarrollo del laboratorio de Elicitación, Análisis, Priorización y Validación de Requisitos para un sistema de información.

El laboratorio tiene como finalidad aplicar técnicas de ingeniería de requisitos para obtener información de los stakeholders, identificar y documentar requisitos funcionales y no funcionales, analizar conflictos, priorizar necesidades y validar los requisitos obtenidos.

El desarrollo sigue buenas prácticas de documentación y trazabilidad, considerando como referencia el estándar IEEE 29148 para la especificación de requisitos.

## Objetivo

Aplicar técnicas de elicitación y gestión de requisitos para identificar las necesidades de los stakeholders, documentarlas como requisitos funcionales y no funcionales, priorizarlas y validarlas, manteniendo la trazabilidad entre los requisitos y las evidencias generadas durante el laboratorio.
